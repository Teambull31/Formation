# JSON et données

Presque toute API, et tout export de mails, répond en **JSON**. Savoir le lire, le trier et en tirer un rapport, c'est le cœur d'une automatisation.

## Lire du JSON

Le JSON a des objets `{"clé": valeur}` et des listes `[ … ]`. En Python : `json.load(f)` lit un fichier, `json.loads(texte)` lit une chaîne. Vous obtenez des `dict` et des `list`. À l'inverse, `json.dumps` produit du texte.

## Filtrer, trier, regrouper

Trois gestes suffisent. **Filtrer** : `[m for m in mails if m["sender"].endswith("@example.test")]`. **Trier** : `sorted(mails, key=lambda m: m["received"], reverse=True)` donne les plus récents d'abord, car les dates ISO se comparent comme du texte. **Regrouper** : un `dict` de listes, avec `groupes.setdefault(nom, []).append(mail)`.

En shell, `jq` fait la même chose : `jq -r '.[] | .subject' mails.json`, ou `jq 'sort_by(.received) | reverse'`.

## Les clés manquantes

Les données réelles sont sales : une clé peut manquer, ou valoir `null`.

!!m["subject"] plante avec KeyError dès qu'une ligne n'a pas de sujet!!

Utilisez `m.get("subject")` puis donnez une valeur de repli, par exemple « (sans objet) ». Vérifiez aussi le type : un `null` n'est pas une chaîne.

!!Regrouper sur l'adresse brute sépare Claire@ et claire@ : normalisez en minuscules!!

## Écrire un rapport Markdown

Un rapport est un simple fichier texte. Construisez une liste de lignes, puis écrivez-la d'un coup avec `open("rapport.md", "w", encoding="utf-8")`. Titres avec `#`, listes avec `- `.

!!Sans encoding="utf-8", les accents peuvent être mal écrits selon la machine!!

Un rapport automatique doit être **déterministe** : mêmes données, mêmes lignes. Triez donc aussi les groupes, sinon l'ordre change d'un lancement à l'autre.

## Exemple

```python
import json
mails = json.load(open("mails.json", encoding="utf-8"))
sujet = (mails[0].get("subject") or "(sans objet)").strip()
nom = mails[0].get("sender", "inconnu@x").split("@")[0].lower()
print(nom, sujet)
```

## Un programme complet, structuré en petites fonctions

Un script de données se découpe toujours de la même façon : **lire**, **nettoyer**, **calculer**, **écrire**. Une fonction par étape, et chacune se teste seule.

```python
# Fichier : rapport.py   Usage : python3 rapport.py chemin/vers/mails.json
import json
import sys
from pathlib import Path

LONGUEUR_MAX = 40


# ── Nettoyer : une valeur brute devient une valeur sûre ──
def nom_expediteur(mail):
    sender = mail.get("sender")
    if not isinstance(sender, str) or not sender.strip():
        return "inconnu"                         # clé absente, null ou vide
    return sender.split("@")[0].strip().lower()  # Claire.Martin@ → claire.martin


def sujet_propre(mail):
    sujet = mail.get("subject")
    if not isinstance(sujet, str):
        return "(sans objet)"                    # absent, null, ou un nombre
    lignes = [l.strip() for l in sujet.splitlines() if l.strip()]
    if not lignes:
        return "(sans objet)"                    # que des espaces ou des sauts de ligne
    premiere = lignes[0]
    return premiere[:LONGUEUR_MAX] + "…" if len(premiere) > LONGUEUR_MAX else premiere


# ── Calculer : regrouper puis trier ──
def regrouper(mails):
    groupes = {}
    for m in mails:
        groupes.setdefault(nom_expediteur(m), []).append(m)
    return groupes


# ── Écrire : une liste de lignes, puis un seul write ──
def lignes_rapport(mails):
    n = len(mails)
    lignes = ["# Rapport des mails", "", f"Total : {n} mail{'s' if n > 1 else ''}"]
    for nom, groupe in sorted(regrouper(mails).items()):            # groupes : ordre alphabétique
        lignes += ["", f"## {nom} ({len(groupe)})"]
        for m in sorted(groupe, key=lambda m: m.get("received") or "", reverse=True):
            recu = m.get("received") or ""
            lignes.append(f"- {recu[:10]} {recu[11:16]} — {sujet_propre(m)}")
    return lignes


def main():
    if len(sys.argv) != 2:
        sys.exit("Usage : python3 rapport.py <mails.json>")
    mails = json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))   # lecture seule
    Path("rapport.md").write_text("\n".join(lignes_rapport(mails)) + "\n", encoding="utf-8")


if __name__ == "__main__":
    main()
```

Pourquoi cette organisation :

- Les fonctions de **nettoyage** sont en haut : tout le reste s'appuie sur elles, et c'est là que vivent les cas tordus (clé absente, `null`, sujet sur plusieurs lignes).
- `lignes_rapport` ne touche aucun fichier : on peut l'appeler dans `python3` sur une petite liste et regarder le résultat.
- `main` est le seul endroit qui lit les arguments et les fichiers.
- `recu[:10]` garde `2026-03-05`, `recu[11:16]` garde `14:30` : une date ISO a toujours la même forme `AAAA-MM-JJTHH:MM:SS`.
- Les groupes sont triés par `sorted(...items())`, et les mails de chaque groupe par date décroissante : le rapport est **déterministe**.

## Pas à pas : écrire rapport.py

1. Regardez les données : `jq '.[0]' kit/fixtures/mails.json`, puis `jq -r '.[].sender' kit/fixtures/mails.json`.
2. Écrivez `nom_expediteur` et testez-la dans `python3` sur `{"sender": "Claire@x"}`, `{}` et `{"sender": None}`.
3. Écrivez `sujet_propre` et testez un sujet de 50 caractères, un sujet `"\n  Bonjour\n"` et un sujet `None`.
4. Écrivez `regrouper`, puis `lignes_rapport`, et affichez le résultat avec `print("\n".join(...))` avant d'écrire le fichier.
5. Ajoutez `main` et lancez : `python3 rapport.py kit/fixtures/mails.json && cat rapport.md`.
6. Testez une liste vide : `echo '[]' > vide.json && python3 rapport.py vide.json` doit écrire `Total : 0 mail`.

**À retenir :** `json.load`, puis filtrer, trier, regrouper ; `.get()` avec repli pour les clés manquantes ; un rapport déterministe écrit en UTF-8.
