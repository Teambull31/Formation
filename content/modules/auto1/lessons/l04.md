# JSON et données

Presque toute API, et tout export de mails, répond en **JSON**. Savoir le lire, le trier et en tirer un rapport, c'est le cœur d'une automatisation.

## Lire du JSON

Le JSON a des objets `{"clé": valeur}` et des listes `[ … ]`. En Python : `json.load(f)` lit un fichier, `json.loads(texte)` lit une chaîne. Vous obtenez des `dict` et des `list`. À l'inverse, `json.dumps` produit du texte.

## Filtrer, trier, regrouper

Trois gestes suffisent. **Filtrer** : `[m for m in mails if m["sender"].endswith("@example.test")]`. **Trier** : `sorted(mails, key=lambda m: m["received"], reverse=True)` donne les plus récents d'abord, car les dates ISO se comparent comme du texte. **Regrouper** : un `dict` de listes, avec `groupes.setdefault(nom, []).append(mail)`.

En shell, `jq` fait la même chose : `jq -r '.[] | .subject' mails.json`, ou `jq 'sort_by(.received) | reverse'`.

## Les clés manquantes

Les données réelles sont sales : une clé peut manquer, ou valoir `null`.

!!m["subject"] plante avec KeyError dès qu'une ligne n'a pas de sujet!!

Utilisez `m.get("subject")` puis donnez une valeur de repli, par exemple « (sans objet) ». Vérifiez aussi le type : un `null` n'est pas une chaîne.

!!Regrouper sur l'adresse brute sépare Claire@ et claire@ : normalisez en minuscules!!

## Écrire un rapport Markdown

Un rapport est un simple fichier texte. Construisez une liste de lignes, puis écrivez-la d'un coup avec `open("rapport.md", "w", encoding="utf-8")`. Titres avec `#`, listes avec `- `.

!!Sans encoding="utf-8", les accents peuvent être mal écrits selon la machine!!

Un rapport automatique doit être **déterministe** : mêmes données, mêmes lignes. Triez donc aussi les groupes, sinon l'ordre change d'un lancement à l'autre.

## Exemple

```python
import json
mails = json.load(open("mails.json", encoding="utf-8"))
sujet = (mails[0].get("subject") or "(sans objet)").strip()
nom = mails[0].get("sender", "inconnu@x").split("@")[0].lower()
print(nom, sujet)
```

**À retenir :** `json.load`, puis filtrer, trier, regrouper ; `.get()` avec repli pour les clés manquantes ; un rapport déterministe écrit en UTF-8.
