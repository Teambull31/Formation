# La boucle d'un agent

Jusqu'ici, votre script **lit** et **résume**. Un **agent** va plus loin : il **agit**. Il tourne en boucle : il **observe** (un mail), il **décide** (que faire ?), il **agit** (un outil). Puis il passe au mail suivant.

## Les outils sont des fonctions déclarées

Un **outil**, c'est une fonction que votre code a écrite et nommée à l'avance. Le modèle n'exécute rien : il **propose** un nom d'outil et un argument, en JSON, par exemple `{"action": "classer", "arg": "urgent"}`. C'est votre code qui décide si l'action est permise et qui l'exécute. **Le modèle propose, le code dispose.**

!!Ne faites jamais `exec`, `os.system` ou `subprocess` sur un texte venu du modèle : c'est offrir un terminal à l'auteur du mail!!

## La liste blanche

Vous déclarez les actions permises : ici `classer`, `archiver_local` et `rien`. C'est une **liste blanche** (allow-list). Tout le reste est refusé, sans discussion : `envoyer_mail`, `supprimer`, une commande shell. L'argument est aussi validé : `classer` n'accepte que quelques étiquettes connues.

!!Une liste noire (« tout sauf supprimer ») oublie toujours une action : la liste blanche, elle, ne laisse passer que ce que vous avez prévu!!

## Plafond d'itérations et journal

Un modèle peut se tromper ou boucler. Fixez un **plafond** : 3 appels au maximum par mail. Après 3 refus, l'agent choisit `rien`. Sans plafond, un modèle qui répond mal en boucle bloque tout.

Tenez un **journal** : une ligne par décision, avec l'**identifiant** du mail et l'action. Le journal ne contient **jamais** l'objet, le corps ni l'expéditeur : un journal est copié, envoyé, archivé, il ne doit pas devenir une seconde boîte mail.

!!Écrire la réponse brute du modèle dans le journal, c'est y recopier le texte hostile d'un mail!!

## Moindre privilège

Un agent qui ne peut que classer et archiver en local ne peut ni fuiter ni détruire. Même si une injection réussit, le pire est une mauvaise étiquette. Les mails suspects (leçon 8) ne passent pas par le modèle : action `rien`, point.

## Exemple

```python
def agir(action, arg):
    if action not in ALLOWED:
        return "refusée"
    ...
```

**À retenir :** observer, décider, agir ; le modèle propose, le code valide contre une liste blanche ; 3 essais au plus ; un journal sans contenu de mail.
