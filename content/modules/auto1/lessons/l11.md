# Gmail et écrire son propre connecteur

Vos mails ne viennent pas toujours d'une API toute faite. Parfois c'est Gmail, parfois un dossier de fichiers exportés. Bonne nouvelle : grâce à l'interface `MailSource` (leçon 5), brancher une nouvelle boîte, c'est écrire **une seule méthode**, `fetch`. Le reste du digest ne change pas.

## Gmail : lecture seule, par OAuth

Gmail se lit avec son API. Vous demandez un seul droit : **`gmail.readonly`**. Pas d'envoi, pas de suppression, pas de « marquer comme lu ». La première fois, une page Google vous demande d'accepter ; le script reçoit un **jeton**, rangé dans un fichier en 0600.

!!Un jeton Gmail donne accès à toute la boîte : jamais dans git, jamais dans un log!!

Le kit contient `GmailSource`. Vous le testez contre le simulateur `mock_gmail`, jamais contre votre vraie boîte. Un compte Google **professionnel** exige l'accord du service informatique, comme pour Outlook.

## L'alternative : IMAP

IMAP est un protocole plus ancien, accepté par presque toutes les messageries. Le kit fournit `ImapSource`. Deux règles : ouvrir le dossier en **`readonly=True`** et lire le mot de passe dans une **variable d'environnement**, pas dans le code. !!Un mot de passe dans le script finit tôt ou tard sur un dépôt!!

## Le contrat MailSource

Un connecteur est une classe avec `fetch(since=None, limit=50)`. Elle renvoie des `Mail` : `id`, `sender`, `subject`, `received` (ISO 8601 en UTC), `body`. Elle est **bornée** (`limit` respecté, `limit <= 0` donne une liste vide), tolérante (un champ manquant reçoit une valeur de repli, sans exception) et **en lecture seule**.

!!Ne journalisez jamais un corps de mail ni un jeton : des compteurs, pas du contenu!!

## Un connecteur maison : un dossier de `.eml`

Un fichier `.eml` est un mail complet enregistré tel quel. Le kit sait déjà le lire : `message_to_mail` transforme un message en `Mail`. Votre connecteur ne fait que quatre choses : lister les `*.eml` du dossier, les lire, convertir chacun, puis laisser `_select` trier et appliquer `since` et `limit`. Pièges : un fichier `notes.txt` ou un sous-dossier n'est pas un mail, et un `.eml` sans `Message-ID` a besoin d'un identifiant de repli (le nom du fichier).

!!Testez contre des données jetables et comparez avec une source connue : sur les mêmes mails, deux sources doivent rendre exactement les mêmes résultats!!

## Exemple

```python
class EmlDirSource:
    def __init__(self, path):
        self.path = Path(path)

    def fetch(self, since=None, limit=50):
        if limit <= 0 or not self.path.is_dir():
            return []
        mails = []
        for f in sorted(self.path.glob("*.eml")):
            try:
                raw = f.read_bytes()
            except OSError:
                continue  # un fichier illisible ne bloque pas les autres
            mails.append(message_to_mail(email.message_from_bytes(raw), f.stem))
        return _select(mails, since, limit)
```

## Le fichier complet : la classe, puis le programme

Un même fichier peut être à la fois une **bibliothèque** (la classe, importable par un autre script) et un **programme** (lancé en ligne de commande). C'est le bloc `if __name__ == "__main__":` qui sépare les deux : il ne s'exécute que si on lance le fichier, pas quand on l'importe.

```python
# Fichier : maison_source.py   Usage : python3 maison_source.py --path DOSSIER [--out digest.json]
import argparse
import email
import json
from pathlib import Path

import digest                                        # ajoute kit/ au chemin : AVANT mail_source
from mail_source import _select, message_to_mail    # noqa: E402


# ── La bibliothèque : le connecteur ──
class EmlDirSource:
    def __init__(self, path):
        self.path = Path(path)                       # accepte str ou Path

    def fetch(self, since=None, limit=50):
        if limit <= 0 or not self.path.is_dir():
            return []                                # le contrat : jamais d'exception ici
        mails = []
        for f in sorted(self.path.glob("*.eml")):    # *.eml directement dans le dossier
            if not f.is_file():
                continue                             # un DOSSIER nommé x.eml n'est pas un mail
            try:
                raw = f.read_bytes()                 # lecture seule
            except OSError:
                continue                             # illisible : on saute, sans bloquer les autres
            mails.append(message_to_mail(email.message_from_bytes(raw), f.stem))  # f.stem = nom sans .eml
        return _select(mails, since, limit)          # tri, since et limit : ceux du kit


# ── Le programme : n'existe que si on lance le fichier ──
def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--path", required=True)
    ap.add_argument("--out", default="digest.json")
    args = ap.parse_args()
    mails = EmlDirSource(args.path).fetch(limit=10_000)
    with open(args.out, "w", encoding="utf-8") as f:
        json.dump([digest.digest_entry(m) for m in mails], f, ensure_ascii=False, indent=2)
    print(f"{len(mails)} mails")


if __name__ == "__main__":
    main()
```

Pourquoi `_select` du kit plutôt qu'un `sorted` maison ? Le contrôle compare votre source à `JsonMailSource` **champ pour champ**. Les deux doivent trier, filtrer et couper exactement de la même façon : réutiliser la même fonction le garantit, réécrire la logique invite une différence subtile (fuseaux horaires, égalités de dates).

## Pas à pas : écrire le connecteur maison

1. Regardez la boîte : `ls -la boite/` montre les trois `.eml` et le leurre `notes.txt`.
2. Ouvrez un `.eml` avec `less` : en-têtes (`From:`, `Subject:`, `Date:`, `Message-ID:`), une ligne vide, puis le corps.
3. Écrivez la classe et testez-la seule dans `python3` : `EmlDirSource("boite").fetch()` doit renvoyer trois `Mail`.
4. Testez les bords : `fetch(limit=0)`, `EmlDirSource("absent").fetch()`, et un dossier créé avec `mkdir piege.eml`.
5. Comparez avec une source connue : sur les mêmes mails exportés en JSON, `JsonMailSource(...).fetch()` doit rendre la même liste.
6. Écrivez `main` sous le bloc `if __name__`, puis lancez : `python3 maison_source.py --path boite`.
7. Vérifiez que la boîte est intacte : `ls -la boite/` affiche les mêmes fichiers, aux mêmes dates.

**À retenir :** un connecteur = `fetch` + le contrat (lecture seule, borné, tolérant) ; Gmail en `gmail.readonly`, IMAP en `readonly=True` ; on teste contre un simulateur et on compare avec une source connue ; jamais de contenu de mail ni de jeton dans les logs.
