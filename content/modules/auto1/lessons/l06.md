# Parler à Ollama

Ollama fait tourner un modèle de langage **sur votre machine**. Vos mails ne sortent pas : c'est la raison de le choisir. Votre script lui parle en HTTP, comme à n'importe quelle API de la leçon 3.

## L'appel /api/generate

Vous envoyez un POST sur `/api/generate` avec un JSON : `model`, `prompt` et `stream`. Mettez **`stream: false`** : vous recevez une seule réponse JSON, dont le champ `response` contient le texte. Sans cela, Ollama renvoie un flux de petits morceaux, plus pénible à lire.

Le kit cache tout cela dans `llm.generate(prompt, model, base_url, timeout)`. L'adresse vient de la variable `OLLAMA_URL` (par défaut `http://localhost:11434`).

## Timeouts et pannes

Un modèle peut être lent, absent ou éteint. Fixez toujours un **timeout** court pour les tests, quelques secondes, et plus long seulement pour un vrai modèle. Toute panne (connexion refusée, timeout, réponse invalide, modèle non installé qui renvoie une erreur 404) devient une seule exception : **`LlmUnavailable`**. Un seul `except` suffit.

!!Sans timeout, un modèle qui ne répond pas bloque votre script, et cron en lance une copie de plus à chaque passage!!

## Le comportement de secours

Si l'IA est indisponible, le script ne doit pas s'effondrer. Il affiche un résultat de **secours** clair, par exemple « (secours) Ollama indisponible », écrit une courte raison sur stderr et se termine proprement. Le tri des mails, lui, continue de marcher sans IA.

!!Un except qui avale tout et répond « OK » cache la panne : l'utilisateur croit avoir un vrai résumé!!

## Pas de données privées dans les journaux

Le prompt contient vos mails. Ne l'affichez jamais dans un message d'erreur ni dans un journal. Le kit ne garde que le type de l'erreur, par exemple `TimeoutError`. Faites pareil.

!!Un `print(f"échec avec le prompt {prompt}")` recopie vos mails dans un fichier de log!!

## Des prompts déterministes

Même entrée, même prompt : n'ajoutez ni date du jour ni identifiant aléatoire. Vous pouvez ainsi comparer et rejouer. Une température basse donne aussi des réponses plus stables.

## Exemple

```python
import sys
from llm import generate, LlmUnavailable

try:
    print(generate("Résume ce texte.", timeout=3))
except LlmUnavailable as e:
    print("(secours) Ollama indisponible")
    print(f"raison : {e}", file=sys.stderr)
```

**À retenir :** `stream: false` et un timeout court ; une seule exception `LlmUnavailable` ; un secours lisible ; jamais le prompt dans les journaux ; des prompts reproductibles.
