# Une source de mails derrière une interface

Votre automatisation lit des mails. Aujourd'hui dans un fichier de test, demain dans une boîte réelle. Si le reste du code ne change pas entre les deux, vous avez gagné des heures.

## Le contrat MailSource

Le kit définit un **contrat** : un objet `MailSource` n'a qu'une méthode, `fetch(since=None, limit=50)`. Elle renvoie une liste de `Mail`, les plus récents d'abord. Peu importe d'où ils viennent.

Un `Mail` est une `dataclass` figée avec cinq champs : `id`, `sender`, `subject`, `received` (date ISO en UTC) et `body`. Les champs ne changent pas d'une source à l'autre.

## Pourquoi isoler la source

Le tri, le résumé et l'affichage ne doivent pas savoir si les mails viennent d'un **JSON**, d'un fichier **mbox** ou, plus tard, d'IMAP. Seule la ligne qui construit la source change : `JsonMailSource(chemin)` ou `MboxMailSource(chemin)`. Le reste du script appelle `fetch` et rien d'autre.

!!Écrire un `if source == "json"` autour de l'affichage : vous dupliquez le code, et les deux versions divergent!!

## Lecture seule et limite

`fetch` **ne modifie jamais** la source : pas de suppression, pas de marquage « lu ». Un test sur vos vrais mails ne peut donc rien casser. Le paramètre `limit` borne le nombre de mails : demandez `limit=5` plutôt que tout charger en mémoire.

!!Les sources du kit renvoient une liste vide pour un chemin inexistant : à vous de vérifier le fichier et d'afficher une erreur claire!!

## Règle de confidentialité

Les mails réels restent **en local**. Vous ne les envoyez jamais à Claude, ni à aucun service externe, ni dans un journal. Pour vous entraîner, utilisez les fixtures du kit, qui sont fictives.

!!Coller un vrai mail dans un chat pour « voir si ça marche » est une fuite de données!!

## Exemple

```python
from mail_source import JsonMailSource, MboxMailSource

source = JsonMailSource("mails.json")  # ou MboxMailSource("boite.mbox")
for mail in source.fetch(limit=5):
    print(f"{mail.sender} | {mail.subject}")
```

**À retenir :** un contrat `fetch` unique, un seul endroit où l'on choisit la source, une lecture seule bornée par `limit`, et des mails réels qui ne quittent jamais la machine.
