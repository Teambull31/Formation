# Brancher Outlook

Jusqu'ici, vos mails venaient d'un fichier. Pour une vraie boîte Outlook, on passe par **Microsoft Graph**, l'API de Microsoft. Vous avez déjà tout appris : c'est un appel d'API (leçon 3) derrière votre interface de source (leçon 5). Le kit fournit `OutlookGraphSource`.

## Perso ou pro

Un compte **personnel** (outlook.com) s'essaie seul, sans demander la permission : c'est le tenant `consumers`. Un compte **professionnel** dépend de l'entreprise : enregistrement de l'application, consentement d'un administrateur, règles de sécurité. !!Ne branchez jamais la boîte pro sans l'accord écrit du service informatique!!

Les étapes réelles sont dans `kit/FICHE_perso_vers_pro.md`. L'essai réel avec votre compte perso est une **étape manuelle facultative**, hors du contrôle automatique du TP : le contrôle n'utilise que le simulateur.

## Se connecter : le device code flow

Votre script n'a pas de navigateur. Le **device code flow** affiche une adresse et un code : vous les saisissez dans un navigateur, vous acceptez, et le script reçoit un **jeton**. Pas de mot de passe dans le script.

!!Un jeton est un mot de passe : jamais dans un dépôt git, jamais dans un log, jamais affiché!!

Le jeton est stocké dans un fichier en **0600** (lisible par vous seul). Le kit le fait pour vous ; vérifiez-le avec `ls -l`. Il le range dans `~/.config/formation-auto1/` (dossier utilisateur), **jamais à côté du script**. Dans le TP, le script lit l'emplacement dans la variable `GRAPH_TOKEN_PATH` : le contrôle la fixe vers un dossier jetable. En vrai, ne la définissez pas.

## Lecture seule : `Mail.Read`

Demandez le **moindre privilège** : le droit `Mail.Read`, rien d'autre. Pas `Mail.ReadWrite`, pas `Mail.Send`. Le connecteur ne fait que des requêtes **GET**, sur un seul serveur.

!!Si un jour une page de consentement réclame « envoyer des mails en votre nom », arrêtez : ce n'est pas le bon droit!!

## `$select` et pagination

Graph renvoie les mails **par pages**. Chaque page indique la suivante dans `@odata.nextLink` : le connecteur la suit, une fois chacune, avec une limite. Il demande seulement les champs utiles avec **`$select`** (id, objet, expéditeur, date, corps) : moins de données reçues, moins de données à protéger.

Dans votre code et vos logs : des **compteurs** (« 12 mails »), jamais de **corps** de mail.

## Exemple

```python
source = OutlookGraphSource("client-id", base_url=url, auth=lambda: "jeton")
mails = source.fetch(limit=10_000)
```

**À retenir :** Graph en lecture seule (`Mail.Read`) ; device code flow ; jeton en 0600 ; `$select` et pages ; jamais de corps ni de jeton dans les logs.
