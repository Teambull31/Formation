# Services, configuration et sondes

Un pod est éphémère : son adresse change à chaque recréation. Pour qu'une application soit joignable, configurée proprement et surveillée, Kubernetes ajoute trois mécanismes.

## Le Service

Un **Service** donne une adresse stable devant un groupe de pods. Il les retrouve par le même mécanisme d'étiquettes : son `selector` désigne les pods cibles, `port` est le port exposé, `targetPort` celui du conteneur. Par défaut le type est `ClusterIP` : joignable seulement depuis l'intérieur du cluster.

```yaml
apiVersion: v1
kind: Service
metadata:
  name: web
spec:
  selector:
    app: web
  ports:
    - port: 80
      targetPort: 8000
```

!!Un sélecteur de Service qui ne correspond à aucun pod ne produit aucune erreur : le service existe mais ne route nulle part!!

## ConfigMap : la configuration

Un **ConfigMap** stocke de la configuration non secrète, hors de l'image. Le conteneur la lit avec `valueFrom: configMapKeyRef` : on change de configuration sans reconstruire l'image.

## Secret : les valeurs sensibles

Un **Secret** est fait pour les mots de passe et les jetons. Le pod le référence avec `valueFrom: secretKeyRef` (nom du Secret, clé). Le manifeste du Deployment ne contient alors jamais la valeur.

!!Ne versionnez jamais un Secret avec ses valeurs : les données y sont encodées en base64, pas chiffrées!!

!!Une sonde de vivacité trop sévère redémarre en boucle une application saine mais lente : réglez-la avec prudence!!

## Les sondes

Une **sonde de disponibilité** (`readinessProbe`) dit si le pod peut recevoir du trafic : tant qu'elle échoue, le Service ne lui envoie rien. Une **sonde de vivacité** (`livenessProbe`) dit si le pod est bloqué : en cas d'échec, Kubernetes le redémarre.

```yaml
readinessProbe:
  httpGet:
    path: /healthz
    port: 8000
livenessProbe:
  httpGet:
    path: /healthz
    port: 8000
  initialDelaySeconds: 10
```

`initialDelaySeconds` laisse à l'application le temps de démarrer avant les premiers tests. Trop court, et Kubernetes tue en boucle une application qui n'a pas fini de démarrer.

**À retenir :** Service avec sélecteur et `targetPort`, ConfigMap, Secret par référence, sondes de disponibilité et de vivacité, délai initial.
